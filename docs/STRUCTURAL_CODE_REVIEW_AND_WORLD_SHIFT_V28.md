# HEX-CORTEX V28 — No More Template-Echo Success and No World Overclaim

## Origin: actual operator results

The operator's Windows checkout passed **1939 tests**, Ruff clean.
Actual Qwen2.5-coder:7b with native Ollama JSON schema returned a syntactically
valid and repository-path-grounded plan, but its complete content was a copy of
the prompt's sample. The response proposed no code changes; it did not read the
source. Therefore it was NOT a meaningful program review despite
plan_status=valid and plan_grounding_ratio=1.

The V27 bounded world residual fitted synthetic +0.4/-0.2 m/s^2 bias from
4 training examples and reached 0 error on 4 same-regime test examples. Those
examples were generated by the same deterministic underlying law and do not
attest a real-world 100% improvement.

## Implemented changes

1. **Honest coding quality:** add a second evidence stage after the existing
StructuredCodePlan syntax/path validator. It recognizes the former canned
response as prompt_template_echo, blocks review status and explains why the
content is not actionable. Valid JSON with no concrete change is classified
no_specific_change_proposed. Even a well-formed proposed change based on
source is marked unverified until independent review/tests.
2. **Structural context instead of a fake complete example:** approved Python
file AST is summarized as bounded function names, line positions, arguments,
branches, exception handlers, returns, call names and classes. No raw source
code, literals or comment text is provided in default mode. The model must
not pretend it has read implementation bodies; those require separately
approved source disclosure. Qwen still cannot edit or run code.
3. **World stress:** the previously fitted constant-acceleration correction
is re-evaluated on synthetic motion with a stable bias, disappearing bias and
reversed bias. Two changed regimes are expected to REGRESS even though the
original synthetic test returned 100% improvement. This shows the limitations
of a stationary bias corrector. No new model is activated.
4. **Windows portable regression:** large-input test parameter IDs no longer
overflow Windows environment limits.

## Remaining capability gaps

Independent code review requires real source context, a trusted test oracle
and human approval before patching. A robust world model needs diverse
calibrated time-stamped observations, uncertainty, out-of-distribution
detection, action-conditioned latent dynamics, independent validation and
a separate safety/control layer. Success with these deliberately tiny CPU
simulations is not evidence that actual objects can be moved safely.
